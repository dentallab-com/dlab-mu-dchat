§ 01

In Scope

Features confirmed for this build. Everything else is excluded by design.

01

Authentication

  • OTP-based login (no password)
  • Restricted to @dentallab.com emails
  • External emails allowed only if whitelisted by admin
  • Non-whitelisted users see "contact admin" message
02

User Profile

  • Name, Profile Picture, Role, Department
  • Admin badge auto-assigned from env-based admin email list
03

Case Creation & Membership

  • Admin-only case creation
  • Unique Case ID per case
  • Optional fields: Patient Name, Doctor Name, Title
  • Admin adds members by email (autocomplete for existing users)
  • Non-existing @dentallab.com users → email invite to register & join
  • Non-existing external users → email auto-added to whitelist + invitation
  • Manual whitelist add by admin → triggers login/register email
04

Case Chat — Private Group

  • Private group per Case ID
  • Users can search and request to join → admin approves
05

Messaging

  • Text messages
  • File attachments via S3 (PDF, Images, Videos) — 25MB limit
06

Chat Dashboard

  • List of joined chats
  • Search by Case ID
  • Pagination (10 chats at a time)
07

Notifications

  • Push notifications via PWA
08

Group Info Screen

  • Case details: Case ID, Title, Patient Name, Doctor Name
  • Member list
09

Roles & Permissions

  • Admin: create case, edit case details, delete entire group, manage members, manage whitelist
  • Regular user: join, send messages & files
10

UI / Other

  • Dark Mode
  • Single device login enforcement
§ 02

Out of Scope

Discussed and intentionally excluded. Not part of this delivery.

Messaging

  • Quote / Reply
  • @Mention
  • Emoji reactions
  • Typing indicator
  • Read receipts / Seen by
  • Individual message edit / delete
  • Message forwarding
  • Drag & drop upload
  • File gallery
  • Bookmark / Star messages

Chat & Group

  • Online / Offline / Last Seen status
  • Pin chats
  • Chat filters (All, Muted, Pinned)
  • Unread message count badge
  • Favorites
  • Users leaving groups voluntarily
  • Admin kick / remove user
  • Case status indicators
  • Auto-archive of inactive cases

Notifications

  • Mute toggle per chat
  • Advanced notification preferences
  • Sound toggle / desktop browser notifications
  • In-app notification bell with list

System / Admin

  • Multi-language support
  • Session management view (multiple devices)
  • Audit log
  • Chat export (PDF / CSV)
§ 03

Phase Plan

Three sequential delivery phases. Earlier phases must ship before later ones begin.

Phase 01
Core MVP
Foundation. Auth, profile, case creation, member onboarding, and core messaging.
  • Authentication
  • User Profile + Admin badge
  • Case Creation (admin only)
  • Member add + invitation flow
  • External user whitelist flow
  • Messaging (text + file)
  • Group Info Screen
Phase 02
Discovery & Experience
Open the system up. Self-service join flow, notifications, and theming.
  • Join request + admin approval
  • Pagination
  • Push notifications
  • Dark Mode
Phase 03
Advanced
Admin tooling and security hardening to close out the build.
  • Admin edit case details
  • Admin delete entire chat group
  • Single device login enforcement
